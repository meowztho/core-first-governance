# Core-First Governance

Provider-neutral governance skills packaged here as a Codex plugin.

Included skills:

- `core-first-orchestration` — primary-agent decision procedure for Core-First use, delegation, context isolation, freshness, and review escalation.
- `core-first-extension-architecture` — canonical ownership/reuse/composition architecture method.
- `core-first-verifier` — fresh read-only Core-First conformance verification.
- `independent-review` — anti-anchored independent review for consequential or difficult-to-verify work.

The **user-facing primary agent remains the orchestrator and final integrator**. Delegating to a Core-First-aware agent never replaces the primary agent's own Core-First obligation when architecture is material.

The skill semantics intentionally avoid depending on provider-specific terms such as Codex subagent, Claude subagent, child session, or tool-agent. Host-specific packaging and installation belong outside the portable governance core.
