# Core-First Governance

Provider-neutral governance skills packaged here as a Codex plugin.

Included Skills:

- `core-first-orchestration` — primary-agent decision procedure for grounded source/prerequisite consumption, Core-First routing, delegated work, observable verification, review escalation, and existing external completion authorities.
- `core-first-extension-architecture` — canonical ownership/reuse/composition architecture method.
- `observable-product-verification` — verifies real user/external runtime outcomes and keeps material raw evidence traceable through the active completion/review boundary.
- `core-first-verifier` — fresh read-only two-phase Core-First conformance verification.
- `independent-review` — anti-anchored independent review for consequential or difficult-to-verify work.

The **user-facing primary agent remains the orchestrator and final integrator**. Grounded preflight and product verification are procedures, not new agent roles or architecture owners.

Portable Skill semantics do not depend on provider-specific subagent, browser, computer-use, protocol, MCP, or external-completion-platform APIs. Host-specific packaging and tooling belong outside the portable governance core.
