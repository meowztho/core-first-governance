# Core-First Governance

Provider-neutral governance skills packaged here as a Codex plugin.

Included skills:

- `core-first-orchestration` — primary-agent decision procedure for Core-First use, delegated work, observable product verification, freshness, and review escalation.
- `core-first-extension-architecture` — canonical ownership/reuse/composition architecture method.
- `observable-product-verification` — verifies real user/external runtime outcomes without confusing tool actions or static correctness with product success.
- `core-first-verifier` — fresh read-only Core-First conformance verification.
- `independent-review` — anti-anchored independent review for consequential or difficult-to-verify work.

The **user-facing primary agent remains the orchestrator and final integrator**. Product verification is a procedure, not another orchestration agent or architecture owner.

Portable Skill semantics do not depend on provider-specific subagent, browser, computer-use, protocol, or MCP APIs. Host-specific packaging and tooling belong outside the portable governance core.
